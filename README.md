# CERCS Website

Custom-built responsive website for the Centre for Educational Research and Consultancy Service (CERCS).

## Files
- `index.html` — self-contained preview (all styling, scripts, logo and photographs embedded).
- `cercs-website/index.html` — website page for normal hosting.
- `cercs-website/styles.css` — responsive styling.
- `cercs-website/script.js` — mobile navigation and enquiry form behaviour.
- `cercs-website/cercs-logo.png` — official CERCS logo.
- `cercs-website/images/` — photographs supplied from the CERCS capability profile.

## Local preview
Open the root `index.html` in Chrome or Edge. It is self-contained and should display without needing the other files.

## Hosting
For GitHub Pages, upload the contents of `cercs-website/` (not the parent folder) into the root of a GitHub repository, so `index.html`, `styles.css`, `script.js`, `cercs-logo.png`, and `images/` sit together at repository root.

## Contact
The website uses CERCS contact information supplied in the capability profile. The enquiry form opens a pre-filled email using the visitor's email application; it is not a server-side form.

## Latest update
The site now includes six additional photographs supplied by CERCS, used in a curated fieldwork gallery and relevant service/about areas. A link to the CERCS Facebook page is included in the footer. Captions are descriptive and avoid claiming a specific role or outcome unless confirmed.
